# OWBN Menu

Os links do menu OWBN na barra de administração.

## Quem pode usar

Administradores do site.

## Como chegar

wp-admin → **OWBN Core** → **Settings** → **OWBN Menu**.

## A tela

- Uma lista de links, cada um com **Title** e **URL**. **×** tira um link; **+ Add Link** acrescenta uma linha.
- **Save Links** salva a lista.
- **Preview** - como o menu fica.

O logo da OWBN fica à direita da barra de administração, ao lado de "Howdy". Passar o mouse sobre ele abre estes links.

## Tarefas comuns

### Acrescentar um link

1. Clique em **+ Add Link**.
2. Preencha **Title** e **URL**.
3. Clique em **Save Links**, e recarregue a página para vê-lo.

## Bom saber

- Um link para outro site da OWbN faz o login do membro no caminho, para ele chegar lá já logado.
- A barra de administração também tem **My Board** sob o nome do membro, que abre o quadro dele em council.owbn.net.

## Solução de problemas

- **Um link novo não aparece.** Recarregue a página depois de salvar; a barra de administração é montada quando a página carrega.
