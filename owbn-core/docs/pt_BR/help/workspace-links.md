# Workspace Links

Os três cartões de links no alto do My Board de cada membro: Resources, Bylaws e Voting.

## Quem pode usar

Administradores do site, e os escritórios de Web e Admin (Coordenadores e a staff deles). Qualquer outra pessoa vê "You do not have permission to edit workspace links."

## Como chegar

wp-admin → **OWBN Core** → **Workspace Links**.

## A tela

- Três grupos, **Resources**, **Bylaws** e **Voting**, cada um uma lista de links com **Link label** e um endereço. **Remove** tira um; **+ Add link** acrescenta um.
- **Save Workspace Links** salva os três.

## Tarefas comuns

### Acrescentar um link a um cartão

1. No grupo do cartão, clique em **+ Add link**.
2. Preencha o rótulo e o endereço.
3. Clique em **Save Workspace Links**.

## Bom saber

- Use o formato de login para links a outro site da OWbN, `https://host/?auth=sso&redirect_uri=/path/`, para os membros chegarem já logados.
- Cada site guarda o seu próprio conjunto: o que você salva aqui aparece só no My Board deste site.

## Solução de problemas

- **"You do not have permission to edit workspace links."** A sua conta precisa de um cargo do escritório de Web ou de Admin, ou de administrador do site.
