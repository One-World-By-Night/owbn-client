# OWBN Menu

The links in the OWBN menu on the admin bar.

## Who can use this

Site admins.

## How to get there

wp-admin → **OWBN Core** → **Settings** → **OWBN Menu**.

## The screen

- A list of links, each with a **Title** and a **URL**. **×** removes a link; **+ Add Link** adds a row.
- **Save Links** saves the list.
- **Preview** - how the menu looks.

The OWBN logo sits at the right of the admin bar, next to "Howdy". Hovering over it opens these links.

## Common tasks

### Add a link

1. Click **+ Add Link**.
2. Fill in **Title** and **URL**.
3. Click **Save Links**, then reload the page to see it.

## Things to know

- A link to another OWbN site signs the member in on the way, so they land there already signed in.
- The admin bar also has **My Board** under the member's name, which opens their board on council.owbn.net.

## Troubleshooting

- **A new link doesn't show.** Reload the page after saving; the admin bar is built when the page loads.
