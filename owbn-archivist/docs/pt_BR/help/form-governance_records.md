# Governance Records

Registra um evento de governança, como o resultado de uma eleição ou uma nomeação interina.

## Quem pode usar

Quem registra: Normalmente um escritório executivo ou o Arquivista.

## Como chegar

No site: a página Archivist Submit → Domain **Governance Records** → Form **Governance Records**. No wp-admin: Archivist → Workspace → aba **New Submission**.

## A tela

| Campo | Obrigatório | O que preencher |
| --- | --- | --- |
| Reporter | Sim | Digite. |
| Details of governance record | Sim | Texto formatado. |
| Associated User | - | por exemplo, a nomeação de um coordenador interino |
| Associated Vote Link | - | por exemplo, o resultado de uma eleição |
| Record Type | Sim | Escolha um. Opções: Interim Appointment, Election Result, Policy Change, Organizational Record, Other. |

O formulário preenche **Submitted By** e o seu email a partir da sua conta.

Os revisores preenchem os próprios campos na página do pedido: **Review Comments**, **Escalation Reason**, **Resolution Notes**, **Resolution Type**.

### Para onde vai

Submission → Archivist Review.

## Tarefas comuns

### Registrar

1. Abra Fazer um Pedido e escolha **Governance Records**, depois **Governance Records**.
2. Preencha os campos acima; o formulário marca com estrela os que têm Sim.
3. Clique em **Submit Request** e acompanhe pela página do pedido.

## Bom saber

- Ele vai direto para o Arquivista.

## Solução de problemas

- **"Submission failed. Please check the form and try again."** Um campo obrigatório está vazio. Preencha todos os campos marcados com Sim acima.
