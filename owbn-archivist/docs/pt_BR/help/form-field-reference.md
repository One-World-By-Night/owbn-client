# Referência dos Campos

Como cada tipo de campo de um formulário do OAT funciona, para que qualquer formulário se leia do mesmo jeito.

## Quem pode usar

Todos que registram ou revisam pedidos.

## Como chegar

Esta é uma página de referência; a página de ajuda de cada formulário aponta para ela.

## Os campos

| Campo | Como funciona |
| --- | --- |
| Chronicle picker | Digite parte do nome, da cidade ou do estado de uma crônica e escolha-a na lista. Alguns formulários só oferecem crônicas em que você é staff |
| Character picker | Digite parte do nome do personagem e escolha-o; **(clear)** recomeça. HSTs, Coordenadores e os escritórios executivos também têm **Create New Character**; veja [Fazer um Pedido](submit.md) |
| Coordinator picker | Escolha um escritório de Coordenador na lista |
| Coordinator checkboxes | Marque cada Coordenador que deve ser avisado; eles recebem email quando o pedido é aprovado |
| Regulation Rules | Digite parte de uma regra e escolha-a, quantas se aplicarem, ou digite texto livre e aperte Enter |
| Controlling Coordinator(s) | Preenchido sozinho a partir das regras que você escolhe; você não digita nele |
| User picker | Procure uma pessoa pelo nome ou email e escolha-a; se não encontrar, digite o nome dela |
| Template | Escolha um modelo e o texto se preenche; você ainda pode editar |
| Signature | Digite o seu nome para assinar |
| ccHub picker | Procure conteúdo personalizado aprovado no ccHub e escolha-o |
| Texto, número, data, endereço web, email | Digite |
| Texto formatado | Uma caixa de texto com negrito, listas e links |
| Lista, caixas de marcar | Escolha um, ou marque os que se aplicam |
| Submitted By | Preenchido a partir da sua conta |

## Tarefas comuns

### Encontrar a ajuda de um campo

1. Leia a linha abaixo do campo no formulário; ela diz o que o campo quer.

## Bom saber

- Os campos marcados com estrela são obrigatórios.
- Alguns campos só aparecem depois de outra resposta, como Blood Magic Category depois de um tipo de conteúdo de Blood Magic.
- Os revisores têm os próprios campos na página do pedido: uma Review Note em Staff Review, uma Coordinator Note em Coordinator Review, e um Resolution Type e Resolution Notes quando o pedido é encerrado.

## Solução de problemas

- **Um seletor não mostra nada.** Digite pelo menos duas letras. Um seletor de personagem só oferece personagens para os quais você pode registrar pedidos.
- **"Submission failed. Please check the form and try again."** Um campo obrigatório está vazio.
