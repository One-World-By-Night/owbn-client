# Manage Satellites

Inclui, altera ou retira os jogos satélites de uma crônica.

## Quem pode usar

Quem registra: O HST ou o CM da crônica principal.

## Como chegar

No site: a página Archivist Submit → Domain **Chronicle Actions** → Form **Manage Satellites**. No wp-admin: Archivist → Workspace → aba **New Submission**.

## A tela

| Campo | Obrigatório | O que preencher |
| --- | --- | --- |
| Your Chronicle | Sim | Escolha a sua crônica. Só aparecem crônicas que não são probatórias nem satélites. |
| What would you like to do? | Sim | Escolha um. Opções: Create a New Satellite Chronicle, Decommission an Existing Satellite, Propose Transition to Full Chronicle. |
| Select Satellite | - | Escolha a crônica satélite. |
| Satellite Chronicle Name | - | Use o mesmo formato do nome do jogo principal. |
| Satellite Chronicle Genre | - | Escolha os que se aplicam. |
| ST of Satellite Chronicle | - | O nome completo, necessário para configurar o site. |
| ST Email Address | - | Um email individual, necessário para configurar o site. |
| Reason / Notes | - | Digite. |

O formulário preenche **Submitted By** e o seu email a partir da sua conta.

Os revisores preenchem os próprios campos na página do pedido: **Review Comments**, **Review Comments**, **Resolution Notes**, **Resolution Notes**, **Resolution Type**, **Resolution Type**.

### Para onde vai

Submission → Membership Review, para criar, encerrar ou mudar a condição de uma crônica → Archivist Review.

## Tarefas comuns

### Registrar

1. Abra Fazer um Pedido e escolha **Chronicle Actions**, depois **Manage Satellites**.
2. Preencha os campos acima; o formulário marca com estrela os que têm Sim.
3. Clique em **Submit Request** e acompanhe pela página do pedido.

## Bom saber

- Só crônicas plenas podem ter satélites; crônicas probatórias e satélites não aparecem.

## Solução de problemas

- **"Submission failed. Please check the form and try again."** Um campo obrigatório está vazio. Preencha todos os campos marcados com Sim acima.
