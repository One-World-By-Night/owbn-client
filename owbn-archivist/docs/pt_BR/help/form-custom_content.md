# Custom Content

Propõe um conteúdo personalizado novo, como uma disciplina de combinação ou um ritual, para aprovação e para o ccHub.

## Quem pode usar

Quem registra: Jogadores, staff, Coordenadores ou o Arquivista; **Submitting As** diz qual.

## Como chegar

No site: a página Archivist Submit → Domain **Custom Content** → Form **Custom Content**. No wp-admin: Archivist → Workspace → aba **New Submission**.

## A tela

| Campo | Obrigatório | O que preencher |
| --- | --- | --- |
| Submitting As | Sim | Escolha um. Opções: As Player, As Staff, As Coordinator, As Archivist. |
| Character | Sim | Procure um personagem que já existe ou crie um novo. |
| Coordinator Office | - | Opcional. Deixe em branco para atribuir pelo tipo de criatura do personagem. |
| Name of Custom Content | Sim | Digite. |
| Content Type | Sim | As opções dependem do tipo de criatura escolhido acima. Opções: Combination Discipline / Technique, Blood Magic: Ritual, Blood Magic: Path, Discipline, Inceptor Discipline, Merit, Path of Enlightenment, Sabbat Ritae, Kuei-jin: Ritual, Fallen Rituals, …. |
| Blood Magic Category | - | A categoria de magia de sangue (por exemplo, Taumaturgia, Necromancia). Opções: Thaumaturgy - Hermetic, Thaumaturgy - Sielanic, Dark Thaumaturgy, Akhu, Assamite Sorcery - Dur-An-Ki, Koldunic Sorcery, Abyssal Mysticism, Natib Athirat, Sadhana, Black Hand Aljusuri, …. |
| Discipline Requirements | - | As disciplinas pré-requisito (uma por linha). |
| XP Cost | Sim | Um número. |
| MET Rules / Mechanics | Sim | A descrição mecânica completa do conteúdo personalizado. |
| Chronicle Where Content Was Created | Sim | Procure a crônica. |
| HST Who Approved | Sim | Preenchido pela crônica escolhida, quando possível. |
| Date of Archival | - | Uma data. |
| Applicable R&U Classifications | - | Escolha as regras de Regulation & Usage que se aplicam. |

O formulário preenche **Submitted By** e o seu email a partir da sua conta.

Os revisores preenchem os próprios campos na página do pedido: **Review Comments**, **Reason for Escalation**, **Resolution Notes**, **Resolution**.

### Para onde vai

Submission → Staff Review (o HST da crônica) → Coordinator Review (todos os Coordenadores necessários) → Archivist Review. Quando você é o Coordenador de um escritório a que o conteúdo pertence, a Staff Review é pulada e o pedido vai direto para a Coordinator Review.

## Tarefas comuns

### Registrar

1. Abra Fazer um Pedido e escolha **Custom Content**, depois **Custom Content**.
2. Preencha os campos acima; o formulário marca com estrela os que têm Sim.
3. Clique em **Submit Request** e acompanhe pela página do pedido.

## Bom saber

- Cada Coordenador em cujo escopo o conteúdo cai o aprova; ele aparece no [ccHub](cchub.md) quando o Arquivista aprova.

## Solução de problemas

- **"Submission failed. Please check the form and try again."** Um campo obrigatório está vazio. Preencha todos os campos marcados com Sim acima.
