# Global DA

Registra uma ação disciplinar de toda a OWbN, que vai para o Coordenador-Chefe e para votação no conselho.

## Quem pode usar

Quem registra: Normalmente um escritório executivo, ou a staff de uma crônica que traz a ação.

## Como chegar

No site: a página Archivist Submit → Domain **Disciplinary Actions** → Form **Global DA**. No wp-admin: Archivist → Workspace → aba **New Submission**.

## A tela

| Campo | Obrigatório | O que preencher |
| --- | --- | --- |
| Disciplinary Record Type | Sim | Escolha um. Opções: New, Reduction. |
| Date of Disciplinary Action | - | Uma data. |
| Player receiving DA | Sim | Procure um jogador. Se não encontrar, digite o nome dele. |
| Details of the disciplinary action | Sim | Texto formatado. |
| Action taken | Sim | Escolha um. Opções: Permanent Ban, Indefinite Ban/3 Strikes, Temporary Ban, 2 Strikes, 1 Strike, Probation, Censure, Condemnation, Removal of Storyteller. |
| Coordinator Removal? | - | Marque se for o caso. |
| Storyteller Removal? | - | Marque se for o caso. |
| ST Removal: Chronicle | - | Procure a crônica. |
| ST Removal: Timeframe | - | Digite. |
| Link to Council vote (guilt) | - | Um endereço web. |
| Link to Council vote (punishment) | - | Um endereço web. |
| Additional Notes | - | Digite. |
| DA Notification | Sim | Escolha um. Opções: System, Manual. |
| Archived | - | Marque se for o caso. |

O formulário preenche **Submitted By** e o seu email a partir da sua conta.

Os revisores preenchem os próprios campos na página do pedido: **Review Comments**, **Escalation Reason**, **Resolution Notes**, **Additional Chronicles Executing This DA**, **Resolution Type**.

### Para onde vai

Submission → Executive Review (o Coordenador-Chefe) → Council Vote → Archivist Review.

## Tarefas comuns

### Registrar

1. Abra Fazer um Pedido e escolha **Disciplinary Actions**, depois **Global DA**.
2. Preencha os campos acima; o formulário marca com estrela os que têm Sim.
3. Clique em **Submit Request** e acompanhe pela página do pedido.

## Bom saber

- **Action Taken** é uma lista fixa; escolha a que corresponde à decisão do conselho.

## Solução de problemas

- **"Submission failed. Please check the form and try again."** Um campo obrigatório está vazio. Preencha todos os campos marcados com Sim acima.
