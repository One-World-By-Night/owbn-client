# Fame Registry

Coloca um personagem no Fame Registry público: a identidade pública, o nível de fama, as influências e quem o conheceria.

## Quem pode usar

Quem registra: O jogador do personagem, ou a staff da crônica dele.

## Como chegar

No site: a página Archivist Submit → Domain **Character Lifecycle** → Form **Fame Registry**. No wp-admin: Archivist → Workspace → aba **New Submission**.

## A tela

| Campo | Obrigatório | O que preencher |
| --- | --- | --- |
| Chronicle | Sim | Procure a crônica. |
| Character Name | Sim | Procure um personagem que já existe ou crie um novo. |
| Character Status | - | Escolha um. Opções: Active, Dead, Inactive, Removed IC, Removed OOC. |
| Fame Level | Sim | O nível do antecedente Fama do personagem. Opções: Fame 3, Fame 4, Fame 5, Fame 6. |
| Public Identity | Sim | O nome mortal ou a identidade pela qual o personagem é conhecido publicamente. |
| Public Description | Sim | Pelo que este personagem é conhecido publicamente? |
| Scope | - | Quem conheceria este personagem? (por exemplo, a comunidade médica, leitores de tabloide) |
| Regulation Rules | - | Escolha as regras de regulamentação que se aplicam. |
| Controlling Coordinator(s) | - | Preenchido sozinho a partir das regras escolhidas. |
| Influence Areas | Sim | Escolha todas as áreas de influência em que o personagem é conhecido publicamente. Opções: Bureaucracy, Church, Finance, Health, High Society, Industry, Legal, Media, Occult, Police, …. |

O formulário preenche **Submitted By** e o seu email a partir da sua conta.

Os revisores preenchem os próprios campos na página do pedido: **Review Note**, **Coordinator Note**, **Resolution Notes**, **Resolution Type**.

### Para onde vai

Submission → Staff Review (o HST da crônica) → Coordinator Review, quando uma regra pede um Coordenador → Archivist Review.

## Tarefas comuns

### Registrar

1. Abra Fazer um Pedido e escolha **Character Lifecycle**, depois **Fame Registry**.
2. Preencha os campos acima; o formulário marca com estrela os que têm Sim.
3. Clique em **Submit Request** e acompanhe pela página do pedido.

## Bom saber

- O que você preenche aqui fica público no [Fame Registry](fame-registry.md) depois da aprovação.

## Solução de problemas

- **"Submission failed. Please check the form and try again."** Um campo obrigatório está vazio. Preencha todos os campos marcados com Sim acima.
