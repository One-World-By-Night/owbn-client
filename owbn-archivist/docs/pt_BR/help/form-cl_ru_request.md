# R&U Request

Registra os itens regulamentados de um personagem: as regras de Regulation & Usage em que ele se encaixa, e os Coordenadores que as controlam.

## Quem pode usar

Quem registra: Jogadores para os próprios personagens, e a staff para os da sua crônica.

## Como chegar

No site: a página Archivist Submit → Domain **Character Lifecycle** → Form **R&U Request**. No wp-admin: Archivist → Workspace → aba **New Submission**.

## A tela

| Campo | Obrigatório | O que preencher |
| --- | --- | --- |
| Chronicle | Sim | Procure a crônica. |
| Character Name | Sim | Procure um personagem que já existe ou crie um novo. |
| Character Status | - | Escolha um. Opções: Active, Dead, Inactive, Removed IC, Removed OOC. |
| Regulation Rules | - | Escolha as regras de regulamentação que se aplicam. |
| Controlling Coordinator(s) | - | Preenchido sozinho a partir das regras escolhidas. |
| Coordinators Who Must Approve | - | Marque cada coordenador cujo poder, regra ou item isto usa (por exemplo, necromancia: o Coordenador Giovanni). Cada um que você marcar precisa aprovar. Uma regra que não diz qual coordenador também precisa disso; sem nada marcado, vai para o coordenador do clã ou da seita do personagem. |

O formulário preenche **Submitted By** e o seu email a partir da sua conta.

Os revisores preenchem os próprios campos na página do pedido: **Review Note**, **Coordinator Note**, **Resolution Notes**, **Resolution Type**.

### Para onde vai

Submission → Staff Review (o HST da crônica) → Coordinator Review, quando uma regra pede um Coordenador → Archivist Review. Quando você é o Coordenador de um escritório a que o pedido pertence, a Staff Review é pulada e o pedido vai direto para a Coordinator Review.

## Tarefas comuns

### Registrar

1. Abra Fazer um Pedido e escolha **Character Lifecycle**, depois **R&U Request**.
2. Preencha os campos acima; o formulário marca com estrela os que têm Sim.
3. Clique em **Submit Request** e acompanhe pela página do pedido.

## Bom saber

- Escolha todas as regras em que o item se encaixa; **Controlling Coordinator(s)** se preenche a partir delas e decide quem revisa.
- Uma regra marcada como Elevated quer dizer que um Coordenador precisa agir; o pedido não se aprova sozinho.
- **Várias regras, uma página de pedido.** Cada regra que você escolhe vira uma linha: o próprio pedido e, depois de aprovado, a própria entrada no personagem. As linhas que têm os mesmos aprovadores abrem juntas numa só página, onde quem revisa pode aprovar todas de uma vez ou vetar uma linha. Uma linha que vai para outro Coordenador é registrada como um pedido separado.
- Marque em **Coordinators Who Must Approve** todo coordenador cujo poder, regra ou item o pedido usa; cada um precisa aprovar antes de o pedido seguir. Uma regra que não diz qual coordenador (como "Appropriate Coordinator") vai para o coordenador do clã ou da seita do personagem, a menos que você marque um.

## Solução de problemas

- **"Submission failed. Please check the form and try again."** Um campo obrigatório está vazio. Preencha todos os campos marcados com Sim acima.
