# Learn Custom Content

Records a character learning a piece of approved custom content from the ccHub.

## Who can use this

Filed by: The character's player, or its chronicle's staff.

## How to get there

On the website: the Archivist Submit page → Domain **Character Lifecycle** → Form **Learn Custom Content**. In wp-admin: Archivist → Workspace → **New Submission** tab.

## The screen

| Field | Required | What to enter |
| --- | --- | --- |
| Chronicle | Yes | Search for the chronicle. |
| Character Name | Yes | Search for an existing character or create a new one. |
| Character Status | - | Pick one. Choices: Active, Dead, Inactive, Removed IC, Removed OOC. |
| Custom Content to Learn | Yes | Search for approved custom content from the ccHub. |
| Regulation Rules | - | Select applicable regulation rules. |
| Controlling Coordinator(s) | - | Automatically populated from selected regulation rules. |
| Coordinators Who Must Approve | - | Tick every coordinator whose power, rule or item this uses (for example necromancy: the Giovanni Coordinator). Each one you tick must approve. A rule that doesn't say which coordinator also needs this; with nothing ticked it goes to the character's clan or sect coordinator. |
| Teacher Name | Yes | Type the name of the character who taught it. There is no search, so nothing shows who holds a power. |
| Teacher's Home Chronicle | Yes | Choose the teacher's home chronicle. Its HST confirms the character can teach this and permits it. |
| Teaching Lineage | - | Type it in. |

The form fills in **Submitted By** and your email from your account.

Reviewers fill in their own fields on the request's page: **Review Note**, **Coordinator Note**, **Resolution Notes**, **Resolution Type**.

### Where it goes

Submission → Staff Review (the chronicle's HST) → Teacher Chronicle Review (the HST of the teacher's home chronicle, when it is a different chronicle) → Coordinator Review, when a rule needs a Coordinator → Archivist Review.

## Common tasks

### File it

1. Open Submit a Request and pick **Character Lifecycle**, then **Learn Custom Content**.
2. Fill in the fields above; the form stars the ones marked Yes.
3. Click **Submit Request** and follow it from its page.

### Learn several items in one go

1. Fill in the form for the first item and click **Add to list** instead of **Submit Request**.
2. A fresh Learn Custom Content form opens with the same character already picked. Pick the next item and fill in its teacher, then click **Add to list** again.
3. Click **Submit all**. Each item is its own request with its own number, and the reviewers see them as one group. The list can also hold other kinds of request; see [Submit a Request](submit.md).

## Things to know

- Only approved custom content can be learned; find it on the [ccHub](cchub.md) first.
- You type the teacher's name and pick their home chronicle yourself. The teacher's chronicle HST then confirms the character can teach it and permits it. When the teacher is from your own chronicle, your HST's review covers it and there is no extra step.

## Troubleshooting

- **"Submission failed. Please check the form and try again."** A required field is empty. Fill in every field marked Yes above.
