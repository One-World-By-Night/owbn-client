# Fame Registry

Puts a character on the public Fame Registry: its public identity, fame level, influences and who would know it.

## Who can use this

Filed by: The character's player, or its chronicle's staff.

## How to get there

On the website: the Archivist Submit page → Domain **Character Lifecycle** → Form **Fame Registry**. In wp-admin: Archivist → Workspace → **New Submission** tab.

## The screen

| Field | Required | What to enter |
| --- | --- | --- |
| Chronicle | Yes | Search for the chronicle. |
| Character Name | Yes | Search for an existing character or create a new one. |
| Character Status | - | Pick one. Choices: Active, Dead, Inactive, Removed IC, Removed OOC. |
| Fame Level | Yes | The character's Fame background level. Choices: Fame 3, Fame 4, Fame 5, Fame 6. |
| Public Identity | Yes | The mortal name or identity this character is publicly known as. |
| Public Description | Yes | What is this character publicly known for? |
| Scope | - | Who would know this character? (e.g. medical community, tabloid readers) |
| Regulation Rules | - | Select applicable regulation rules. |
| Controlling Coordinator(s) | - | Automatically populated from selected regulation rules. |
| Influence Areas | Yes | Select all influence areas where this character is publicly known. Choices: Bureaucracy, Church, Finance, Health, High Society, Industry, Legal, Media, Occult, Police, …. |

The form fills in **Submitted By** and your email from your account.

Reviewers fill in their own fields on the request's page: **Review Note**, **Coordinator Note**, **Resolution Notes**, **Resolution Type**.

### Where it goes

Submission → Staff Review (the chronicle's HST) → Coordinator Review, when a rule needs a Coordinator → Archivist Review.

## Common tasks

### File it

1. Open Submit a Request and pick **Character Lifecycle**, then **Fame Registry**.
2. Fill in the fields above; the form stars the ones marked Yes.
3. Click **Submit Request** and follow it from its page.

## Things to know

- What you enter here is public on the [Fame Registry](fame-registry.md) once approved.

## Troubleshooting

- **"Submission failed. Please check the form and try again."** A required field is empty. Fill in every field marked Yes above.
