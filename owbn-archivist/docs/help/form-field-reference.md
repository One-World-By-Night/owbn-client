# Form Field Reference

How each kind of field on an OAT form works, so any form reads the same way.

## Who can use this

Everyone who files or reviews requests.

## How to get there

This is a reference page; every form's help page links here.

## The fields

| Field | How it works |
| --- | --- |
| Chronicle picker | Type part of a chronicle's name, city or state and pick it from the list. Some forms only offer chronicles you are staff of |
| Character picker | Type part of the character's name and pick it; **(clear)** starts over. HSTs, Coordinators and the exec offices also get **Create New Character**; see [Submit a Request](submit.md) |
| Coordinator picker | Pick a Coordinator office from the list |
| Coordinator checkboxes | Tick each Coordinator who should be told; they are emailed when the request is approved |
| Regulation Rules | Type part of a rule and pick it, as many as apply, or type free text and press Enter |
| Controlling Coordinator(s) | Fills itself in from the rules you pick; you don't type in it |
| User picker | Search for a person by name or email and pick them; if they aren't found, type their name |
| Template | Pick a template and the text fills in; you can still edit it |
| Signature | Type your name to sign |
| ccHub picker | Search approved custom content on the ccHub and pick it |
| Text, number, date, web address, email | Type it in |
| Formatted text | A text box with bold, lists and links |
| List, checkboxes | Pick one, or tick any that apply |
| Submitted By | Filled in from your account |

## Common tasks

### Find a field's own help

1. Read the line under the field on the form; it says what the field wants.

## Things to know

- Fields marked with a star are required.
- Some fields only appear after another answer, such as Blood Magic Category after a Blood Magic content type.
- Reviewers have their own fields on the request's page: a Review Note at Staff Review, a Coordinator Note at Coordinator Review, and a Resolution Type and Resolution Notes when the request is closed.

## Troubleshooting

- **A picker shows nothing.** Type at least two letters. A character picker only offers characters you can file for.
- **"Submission failed. Please check the form and try again."** A required field is empty.
