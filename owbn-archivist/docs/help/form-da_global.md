# Global DA

Records an OWbN-wide disciplinary action, which goes to the Head Coordinator and a council vote.

## Who can use this

Filed by: Usually an exec office, or a chronicle's staff bringing the action.

## How to get there

On the website: the Archivist Submit page → Domain **Disciplinary Actions** → Form **Global DA**. In wp-admin: Archivist → Workspace → **New Submission** tab.

## The screen

| Field | Required | What to enter |
| --- | --- | --- |
| Disciplinary Record Type | Yes | Pick one. Choices: New, Reduction. |
| Date of Disciplinary Action | - | A date. |
| Player receiving DA | Yes | Search for a player. If not found, type their name. |
| Details of the disciplinary action | Yes | Formatted text. |
| Action taken | Yes | Pick one. Choices: Permanent Ban, Indefinite Ban/3 Strikes, Temporary Ban, 2 Strikes, 1 Strike, Probation, Censure, Condemnation, Removal of Storyteller. |
| Coordinator Removal? | - | Tick it if it applies. |
| Storyteller Removal? | - | Tick it if it applies. |
| ST Removal: Chronicle | - | Search for the chronicle. |
| ST Removal: Timeframe | - | Type it in. |
| Link to Council vote (guilt) | - | A web address. |
| Link to Council vote (punishment) | - | A web address. |
| Additional Notes | - | Type it in. |
| DA Notification | Yes | Pick one. Choices: System, Manual. |
| Archived | - | Tick it if it applies. |

The form fills in **Submitted By** and your email from your account.

Reviewers fill in their own fields on the request's page: **Review Comments**, **Escalation Reason**, **Resolution Notes**, **Additional Chronicles Executing This DA**, **Resolution Type**.

### Where it goes

Submission → Executive Review (the Head Coordinator) → Council Vote → Archivist Review.

## Common tasks

### File it

1. Open Submit a Request and pick **Disciplinary Actions**, then **Global DA**.
2. Fill in the fields above; the form stars the ones marked Yes.
3. Click **Submit Request** and follow it from its page.

## Things to know

- **Action Taken** is a fixed list; pick the one that matches the council's decision.

## Troubleshooting

- **"Submission failed. Please check the form and try again."** A required field is empty. Fill in every field marked Yes above.
