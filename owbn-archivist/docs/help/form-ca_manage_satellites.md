# Manage Satellites

Adds, changes or removes a chronicle's satellite games.

## Who can use this

Filed by: The parent chronicle's HST or CM.

## How to get there

On the website: the Archivist Submit page → Domain **Chronicle Actions** → Form **Manage Satellites**. In wp-admin: Archivist → Workspace → **New Submission** tab.

## The screen

| Field | Required | What to enter |
| --- | --- | --- |
| Your Chronicle | Yes | Select your chronicle. Only non-probationary, non-satellite chronicles are shown. |
| What would you like to do? | Yes | Pick one. Choices: Create a New Satellite Chronicle, Decommission an Existing Satellite, Propose Transition to Full Chronicle. |
| Select Satellite | - | Choose the satellite chronicle. |
| Satellite Chronicle Name | - | Use the same format as the parent game name. |
| Satellite Chronicle Genre | - | Pick any that apply. |
| ST of Satellite Chronicle | - | Full name required for website setup. |
| ST Email Address | - | Individual email required for website setup. |
| Reason / Notes | - | Type it in. |

The form fills in **Submitted By** and your email from your account.

Reviewers fill in their own fields on the request's page: **Review Comments**, **Review Comments**, **Resolution Notes**, **Resolution Notes**, **Resolution Type**, **Resolution Type**.

### Where it goes

Submission → Membership Review, for creating, decommissioning or changing a chronicle's standing → Archivist Review → Web Team Setup, where the web team builds or changes the chronicle's record and the ST's account and approves to finish.

## Common tasks

### File it

1. Open Submit a Request and pick **Chronicle Actions**, then **Manage Satellites**.
2. Fill in the fields above; the form stars the ones marked Yes.
3. Click **Submit Request** and follow it from its page.

## Things to know

- Only full chronicles can have satellites; probationary and satellite chronicles aren't offered.

## Troubleshooting

- **"Submission failed. Please check the form and try again."** A required field is empty. Fill in every field marked Yes above.
